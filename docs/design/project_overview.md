# FindTutor - Project Overview

## 1. Introduction
FindTutor is a peer-to-peer tutoring platform
that connects students who need help with
students who can teach.

## 2. Objectives
- Connect students with peer tutors.
- Make tutor searching easier.
- Allow students to request tutoring sessions.
- Support online and in-person learning.

## 3. Target Users
- Students looking for tutors.
- Students who want to become tutors.

## 4. Main Features
- Student registration and login.
- Student and tutor profiles.
- Tutor search and filters.
- Tutoring requests.
- Tutor availability.
- Reviews and ratings.
