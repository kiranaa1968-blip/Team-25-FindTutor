# System Design

## 1. System Architecture

FindTutor uses a Flutter application
to provide the user interface.

The system is organized into:

- Frontend: Flutter and Dart
- Database: SQLite
- Data Management: AppDatabase

## 2. Frontend

The frontend is responsible for displaying
screens and receiving user input.

Main screens:

- Home Screen
- Login Screen
- Dashboard Screen
- Tutor Search Screen
- Profile Screen

## 3. Database

SQLite stores application data locally.

Main tables:

- Students
- Tutors
- Tutoring Requests

## 4. Application Structure

- models/: Stores data models.
- screens/: Contains application screens.
- database/: Handles database operations.

## 5. Technology Stack

| Technology | Purpose |
|---|---|
| Flutter | User Interface |
| Dart | Programming Language |
| SQLite | Local Database |
| GitHub | Version Control |
